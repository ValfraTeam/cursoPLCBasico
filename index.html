📋 Generalidades de los PLC

Un PLC (Controlador Lógico Programable) es un dispositivo electrónico diseñado para el control de procesos industriales mediante una lógica programable almacenada en memoria.

Estructura interna:

  • CPU — procesa el programa de usuario
  • Memoria — programa + datos (RAM, ROM/EPROM)
  • Módulos de E/S — entradas y salidas digitales/analógicas
  • Fuente de alimentación — 24 VDC / 220 VAC
  • Bus de comunicaciones interno

Estructura externa:

  • Bornes de entrada (sensores, pulsadores, fines de carrera)
  • Bornes de salida (contactores, válvulas, lámparas)
  • Puerto de programación (USB, RS-232, Ethernet)
  • Display y LEDs de diagnóstico

🔩 Tipos de PLC

PLCs Compactos: CPU, E/S y fuente integrados en una sola carcasa. Ideales para máquinas pequeñas y medianas.

  • Menor costo y tamaño reducido
  • Expansión limitada por módulos adicionales
  • Ej: Siemens S7-1200, Allen-Bradley Micro820

PLCs Modulares: Chasis o rack con módulos intercambiables. Permiten alta flexibilidad.

  • Alta capacidad de E/S
  • Fácil mantenimiento (hot-swap en algunos modelos)
  • Ej: Siemens S7-300/400, Allen-Bradley ControlLogix

Criterios de selección:

  • Cantidad y tipo de E/S requeridas
  • Velocidad de ciclo de scan necesaria
  • Protocolos de comunicación (Profibus, Ethernet/IP)
  • Temperatura ambiente y grado de protección IP

📐 Norma IEC 61131-3

La norma IEC 61131-3 estandariza los lenguajes de programación para PLC a nivel mundial. Define 5 lenguajes:

  • LD — Ladder Diagram (Diagrama de escalera)
  • FBD — Function Block Diagram
  • ST — Structured Text (tipo Pascal)
  • IL — Instruction List (tipo Assembler)
  • SFC — Sequential Function Chart

Todos los lenguajes son equivalentes en potencia. La elección depende del proceso y del programador.

LD más usado FBD procesos ST avanzado

🏗️ Modelo de software IEC 61131-3

La norma también define una jerarquía de software:

  • Configuración — representa un sistema PLC completo
  • Recurso — una CPU dentro de la configuración
  • Programa (POO) — unidad lógica principal
  • Bloque de función (FB) — con memoria propia
  • Función (FC) — sin memoria, solo retorna valor

Tipos de datos básicos:

  • BOOL — 1 bit (TRUE/FALSE)
  • INT/DINT — entero 16/32 bits
  • REAL — punto flotante 32 bits
  • TIME — duración temporal (T#5s)
  • STRING — cadena de caracteres

🪜 Objetos básicos Ladder

Contactos:

  • Contacto NA (nivel) — cierra cuando variable = TRUE. Símbolo: —[ ]—
  • Contacto NC (negado) — cierra cuando variable = FALSE. Símbolo: —[/]—
  • Contacto por flanco ascendente — un ciclo en subida —[P]—
  • Contacto por flanco descendente — un ciclo en bajada —[N]—

Bobinas:

  • Bobina normal — activa mientras condición TRUE —( )—
  • Bobina negada (NOT) — inversa de condición —(/)—
  • Bobina SET (retentiva ↑) — activa y queda activa —(S)—
  • Bobina RESET (retentiva ↓) — desactiva la variable —(R)—

⏱️ Temporizadores y Contadores

Temporizadores IEC:

  • TON — On-delay. Activa salida después de T retardo
  • TOF — Off-delay. Desactiva salida después de T retardo
  • TP — Pulso de duración fija, no reiniciable
  • TONR — Acumulativo (retentivo entre ciclos)

Contadores IEC:

  • CTU — Contador ascendente (count up)
  • CTD — Contador descendente (count down)
  • CTUD — Bidireccional

Bloques de comparación:

  • EQ, NE, GT, GE, LT, LE — comparan dos valores
  • ADD, SUB, MUL, DIV — operaciones aritméticas

🥁 Tambor secuenciador (Drum)

El tambor secuenciador es una técnica para programar secuencias de pasos discretos, como un carrusel de estados.

  • Define N pasos con combinaciones de salidas
  • Avanza al siguiente paso por condición o tiempo
  • Útil en cintas transportadoras, llenadoras, lavadoras
  • Se implementa con contador + comparadores

La implementación moderna usa SFC (Grafcet) o bloques CASE en ST, pero en Ladder se replica con CTU + comparadores.

🔄 Ciclo de Scan del PLC

El programa del PLC se ejecuta cíclicamente:

  • 1. Lectura de entradas — copia el estado de las entradas físicas a la imagen de proceso
  • 2. Ejecución del programa — proceso el código de arriba a abajo
  • 3. Escritura de salidas — escribe la imagen de proceso a las salidas físicas
  • 4. Tareas de fondo — comunicación, autodiagnóstico

El tiempo de scan típico es 1–50 ms. Para eventos rápidos se usan interrupciones de hardware.

Ejercicios propuestos

Ej. 01 · U1 Circuito Start/Stop de un motor ▼

Programar el arranque y paro de un motor con enclavamiento (auto-retención).

  1. Entrada I0.0 = Pulsador START (NA)
  2. Entrada I0.1 = Pulsador STOP (NC)
  3. Salida Q0.0 = Contactor KM1
  4. Implementar el enclavamiento con contacto Q0.0 en paralelo con START
  5. Probar en simulador: arrancar, detener, verificar auto-retención
Ej. 02 · U1 Control de semáforo 3 luces ▼

Controlar un semáforo con 3 salidas (rojo, amarillo, verde) usando SET/RESET.

  1. Q0.0 = Rojo, Q0.1 = Amarillo, Q0.2 = Verde
  2. Al iniciar: rojo activo, los demás apagados
  3. I0.0 = sensor de paso → verde, luego amarillo, luego rojo
  4. Usar bobinas SET/RESET para asegurarse que solo una luz esté activa
Ej. 03 · U3 Temporizador TON — arranque temporizado ▼

Un motor arranca 5 segundos después de presionar START.

  1. I0.0 = Pulsador START
  2. Instanciar TON con PT = T#5s
  3. Conectar bobina del motor a la salida Q del temporizador
  4. I0.1 = STOP resetea el temporizador y para el motor
  5. Verificar que ET (elapsed time) avanza correctamente en simulador
Ej. 04 · U3 Temporizador TOF — ventilador con post-marcha ▼

Un ventilador sigue funcionando 10 segundos después de apagar la máquina.

  1. I0.0 = Marcha máquina
  2. Q0.0 = Ventilador (activo mientras máquina ON + 10s después)
  3. Usar TOF con PT = T#10s
  4. Cuando I0.0 cae a FALSE, el TOF empieza a contar
  5. Al llegar a PV, Q del TOF se pone FALSE y el ventilador para
Ej. 05 · U3 Contador CTU — llenado de envases ▼

Una llenadora debe detener el proceso al completar 100 envases.

  1. I0.0 = Sensor fotoeléctrico (flanco ascendente por envase)
  2. I0.1 = Reset del contador (inicio de lote)
  3. CTU con PV = 100
  4. Q del CTU activa alarma y detiene la cinta (Q0.1)
  5. Mostrar CV en display HMI (simular con variable)
Ej. 06 · U4 Tambor secuenciador — cinta con 4 pasos ▼

Secuencia automática de 4 pasos controlada por tiempo.

  1. Paso 1 (5s): Motor A arranca
  2. Paso 2 (3s): Motor A + Motor B activos
  3. Paso 3 (4s): Solo Motor B activo
  4. Paso 4: Todo apagado, ciclo terminado
  5. Implementar con CTUD + TON + comparadores EQ
  6. I0.0 = inicio de ciclo, I0.1 = parada de emergencia
Ej. 07 · U4 Comparador — control de nivel de tanque ▼

Controlar una bomba según el nivel de un tanque con señal analógica.

  1. IW64 = entrada analógica sensor de nivel (0–27648 = 0–100%)
  2. Si nivel < 20% → activar bomba Q0.0
  3. Si nivel > 80% → desactivar bomba Q0.0
  4. Usar bloques CMP (LT y GT) con histéresis
  5. Usar SET/RESET para evitar oscilaciones
